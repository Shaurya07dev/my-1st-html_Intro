# My First Webpage: A Journey into HTML

[![HTML](https://img.shields.io/badge/HTML-5-E34F26?style=for-the-badge&logo=html5&logoColor=white)](https://developer.mozilla.org/en-US/docs/Web/HTML)

This repository contains the code for my very first webpage, created using pure HTML.  It's a simple project, but it represents an important step in my web development journey.

**[View the live webpage here](https://shaurya07dev.github.io/my-1st-html_Intro/)**


## Description

This project was born out of a desire to get hands-on experience with HTML. As I was learning the basics, I wanted to create something tangible, a small project that would solidify my understanding.  The webpage is a basic HTML structure, and was created as a learning exercise. I followed Code With Harry's HTML tutorial playlist on YouTube while making this project.

## Features

* **Pure HTML:** The page is built entirely with HTML, demonstrating fundamental web structure.
* **Simple Structure:** It includes basic HTML elements.
* **First Steps:** This project represents my initial foray into web development.

## Technologies Used

* HTML

## Setup

Since this is a static HTML page, there's no complex setup required. You can:

1.  **View Directly:** Simply open the live webpage in your browser: [https://shaurya07dev.github.io/my-1st-html_Intro/](https://shaurya07dev.github.io/my-1st-html_Intro/)
2.  **Clone the Repository:** If you want to examine the code, clone this repository:

    ```bash
    git clone [https://github.com/Shaurya07dev/my-1st-html_Intro.git](https://github.com/Shaurya07dev/my-1st-html_Intro.git)
    ```
3.  **Open Locally:** Navigate to the cloned directory and open the `index.html` file in your web browser.
